# Arbeitspakete

Gepflegt von **Jarvis**. Ein Arbeitspaket (AP) ist eine abgegrenzte Aufgabe mit klarem Ergebnis, die in ein bis wenigen Sitzungen fertig wird. Vorlage: [_vorlage.md](_vorlage.md).

Ablauf: `vorgeschlagen` → Sirat gibt frei → `freigegeben` → `in Arbeit` → `fertig (geprüft)` (oder `blockiert` / `verworfen`). Code entsteht nur, wenn Sirat es für das jeweilige Paket ausdrücklich ansagt.

Als Board ansehen: `node tools/cockpit/server.mjs` → http://localhost:4777
